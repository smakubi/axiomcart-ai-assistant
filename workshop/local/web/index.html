Listen, speak, interrupt

Compare the same Python voice pipeline over two transports. Use headphones. The assistant voice is AI-generated. Offline mode plays a quiet tone instead of calling AI.

Disconnected

Unchecked: the microphone stays active, and one new turn waits for the current reply to finish. Checked: speaking cancels the old reply. Say a complete request, then pause. Each request is independent; this exercise has no conversation memory.



WebSocket sends 24 kHz mono PCM in 20 ms chunks; playback acknowledgments bound the output backlog. WebRTC uses a media track; the browser and Python media stack handle codecs and packet timing. Both need the same turn and cancellation logic. A small device/network playback tail can remain after interruption.
